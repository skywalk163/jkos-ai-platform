## 二、M19.1 PostgreSQL 迁移层真实化

### 2.1 真实转换能力

- **类型映射**（`SQLITE_TO_PG_TYPE_MAP`）：`DATETIME`→`TIMESTAMP`、`JSON`→`JSONB`、`BLOB`→`BYTEA`、`BOOLEAN`→`BOOLEAN` 等。
- **DDL 生成三档取源**（`generate_migration_sql`）：显式 DDL 解析 → `sqlite_master` 内省 → 通用骨架兜底；CREATE TABLE 列定义按括号/引号感知的顶层逗号切分；`AUTOINCREMENT`+`INTEGER`+`PRIMARY KEY`→`SERIAL PRIMARY KEY`；DEFAULT 表达式转换（`STRFTIME`/`DATETIME`→`CURRENT_TIMESTAMP`，未知类型→TEXT）；索引随表产出且 `IF NOT EXISTS`；SQLite `RAISE` 触发器以注释保留待手工改写。
- **数据迁移**（`generate_data_migration_sql`）：`PRAGMA table_info`/`SELECT *` 从源库导出真实数据为逐行 `INSERT`，`_sql_literal` 覆盖单引号转义（`O'Reilly`→`O''Reilly`）、JSON→`::jsonb`、bytes→`E'\\x..'`、时间类型字面量。
- **产物落盘**（`write_migration_artifacts`）：`migration_{plan_id}_{table}.sql`，含边界标记（`-- 迁移计划 / -- 由 … 生成 / -- BEGIN SCHEMA / -- BEGIN DATA`）；`plan_id` 为 `uuid4().hex[:8]`。

### 2.2 执行与连接池

- `execute_migration`（同步，仅生成产物，目标库无需在线）+ `execute_migration_async`（真实 asyncpg 执行，异常置 `FAILED`，`finally` 关闭所有异步池）。
- `ConnectionPoolManager.get_async_pool()`：懒加载 asyncpg 池（`min_size=1`、`max_size=pool_size+overflow`、`timeout=3s`）；asyncpg 未安装→`ConnectionError`（"asyncpg 未安装…"）；目标库不可达→`ConnectionError`（"无法连接 PostgreSQL"）；`get_stats()` 增加 `async_pool_count`。

### 2.3 本次收口的三个生产修复（asyncpg 专属）

| 级别 | 问题 | 修复 |
| --- | --- | --- |
| 高 | asyncpg 扩展协议拒绝单条多语句与裸注释，迁移 SQL 直接执行报 `syntax error at end of input` | `_execute_async_script` 逐行缓冲，跳过空行/`--` 注释，仅完整 `;` 结尾才提交（`postgres.py:499-522`） |
| 高 | `sqlite_master` 内省所得索引/触发器语句无 `;` 结尾，报 `syntax error at or near "CREATE"` | `_terminate_statement_lines` 为非空非注释行补全 `;`（`postgres.py:237-255`） |
| 中 | asyncpg.connect/create_pool 不认 `username=` 关键字 | 测试统一经 `_pg_conn_kwargs()` 映射 `username=`→`user=`（`tests/test_m19_duelrun.py`） |

## 三、M19.2 NATS 总线真实化

### 3.1 真实接入与零依赖降级

- `NatsEventBus.connect()` 函数内 `import nats`（可确定性模拟缺失 NATS）；`mode` 区分 `nats` / `embedded`。
- 无 NATS 服务 / 不可达时自动降级内嵌内存模式，对外契约（publish 返回 True、订阅回环、get_event）不变，**零新增硬依赖**（可选依赖组 `nats = ["nats-py>=2.6.0"]`）。
- `_event_to_dict` 以 `getattr` 回退增强 `payload` / `metadata` / `status`，并补 `created_at`，保证 Builder 等富对象也能序列化。

### 3.2 发布 / 订阅

- publish 走真实 subject（携带完整事件信封），失败回滚为 `PENDING` 且**不写本地事件表**（与降级语义一致）。
- subscribe 联动真实 NATS 订阅（支持 queue group / durable）；远端消息经信封解码 → `handle_event` 幂等分发；`unsubscribe` / `disconnect` 联动取消订阅与关闭连接。
