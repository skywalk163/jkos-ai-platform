# 极快AI操作系统 (JKOS) - 生产部署指南

## 环境要求

- Python 3.11+
- SQLite (内置)
- Redis (可选，用于缓存)
- NATS (可选，用于事件总线)

## 快速部署

### 1. 安装依赖

```bash
cd dsh-ai-platform
pip install -e ".[prod]"
```

### 2. 配置环境变量

```bash
# 复制 .env 文件
cp .env.example .env

# 编辑配置
vim .env
```

### 3. 初始化数据库

```bash
python server.py --init
```

### 4. 启动服务

```bash
# 启动 API 服务 (默认 0.0.0.0:8000)
python server.py

# 只启动 MCP Server
python server.py --mcp --port 3000

# 启动后台工作进程
python server.py --worker
```

## Docker 部署

### 构建镜像

```bash
docker build -t dsh-ai-platform .
```

### 运行容器

```bash
docker run -d \
  --name dsh-ai \
  -p 8000:8000 \
  -p 3000:3000 \
  -v $(pwd)/.env:/app/.env \
  -v $(pwd)/data:/app/data \
  dsh-ai-platform
```

## FreeBSD 部署

### 1. 安装依赖

```bash
# 安装 Python
pkg install python311

# 安装 pip
pkg install py311-pip

# 安装依赖
pip install -e ".[prod]"
```

### 2. 创建系统服务

```bash
# 创建服务文件
cat > /usr/local/etc/rc.d/dsh-ai << 'EOF'
#!/bin/sh

. /etc/rc.subr

name="dsh_ai"
rcvar="dsh_ai_enable"

dsh_ai_enable="${dsh_ai_enable:-NO}"
dsh_ai_user="ai"
dsh_ai_group="ai"
dsh_ai_chdir="/usr/dsh-ai-platform"
dsh_ai_command="/usr/local/bin/python311"
dsh_ai_pidfile="/var/run/dsh-ai.pid"

command="${dsh_ai_command}"
command_args="server.py"
command_chroot="${dsh_ai_chdir}"
command_user="${dsh_ai_user}:${dsh_ai_group}"

load_rc_config $name
run_rc_command "$1"
EOF

chmod +x /usr/local/etc/rc.d/dsh-ai
```

### 3. 启动服务

```bash
# 启用服务
sysrc dsh_ai_enable=YES

# 启动服务
service dsh-ai start

# 查看状态
service dsh-ai status
```

## 配置项

### 数据库

```bash
# SQLite (默认)
DSH_DB_PATH=/var/dsh/dsh.db

# PostgreSQL (可选)
DSH_PG_HOST=localhost
DSH_PG_PORT=5432
DSH_PG_DB=dsh_ai
DSH_PG_USER=dsh_user
DSH_PG_PASSWORD=your_password
```

### LLM

```bash
# DeepSeek (默认)
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_MODEL=deepseek-chat

# OpenAI (可选)
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://api.openai.com
OPENAI_MODEL=gpt-4
```

### 缓存

```bash
# Memory (默认)
DSH_CACHE_BACKEND=memory

# Redis (可选)
DSH_REDIS_URL=redis://localhost:6379/0
```

### 事件总线

```bash
# 内嵌 (默认)
DSH_BUS_BACKEND=embedded

# NATS (可选)
DSH_NATS_URL=nats://localhost:4222
```

### 通知

```bash
# 企业微信
DSH_WECOM_CORPID=xxx
DSH_WECOM_CORPSECRET=xxx
DSH_WECOM_AGENTID=xxx

# 钉钉
DSH_DINGTALK_APPKEY=xxx
DSH_DINGTALK_APPSECRET=xxx
```

## 故障排除

### 服务无法启动

```bash
# 检查端口占用
netstat -an | grep 8000

# 检查日志
tail -100 logs/dsh.log
```

### 数据库锁定

```bash
# SQLite WAL 模式
# 检查是否有残留的 wal/shm 文件
ls -la /var/dsh/

# 删除残留文件
rm -f /var/dsh/dsh.db-wal /var/dsh/dsh.db-shm
```

### LLM API 调用失败

```bash
# 检查 API Key
curl -H "Authorization: Bearer $OPENAI_API_KEY" \
  https://api.deepseek.com/v1/models

# 检查网络连通性
ping api.deepseek.com
```

## 安全建议

1. **API Key 管理**
   - 不要将 .env 文件提交到版本控制
   - 定期轮换 API Key
   - 使用最小权限原则

2. **数据库安全**
   - 定期备份
   - 设置文件权限
   - 监控异常访问

3. **网络隔离**
   - 防火墙限制
   - VPN 访问
   - HTTPS 加密

4. **审计日志**
   - 保留审计日志
   - 定期审查
   - 异常告警
